# ETF 觀察表（PWA）

手機優先的台股 ETF 觀察網頁：市價、折溢價、資產規模、受益人數、管理費、殖利率、資金流向、成份股。
網址：https://jey2204-creator.github.io/etf/

## 資料怎麼更新
GitHub Actions（`.github/workflows/update.yml`）每個交易日台灣時間 14:23、17:43 執行
`scripts/update.py`，抓官方公開資料後寫入 `data/etf.json`，並把當日快照附加到 `data/history.csv`。
也可以在 GitHub 的 Actions → 更新 ETF 資料 → Run workflow 手動執行。

| 欄位 | 來源 | 頻率 |
|---|---|---|
| 市價、預估淨值、已發行單位數 | 證交所 基本市況報導 MIS | 每日 |
| 折溢價、資產規模 | 由上列資料計算（規模 = 單位數 × 淨值） | 每日 |
| 成交量 | 證交所 每日收盤行情（上市）、櫃買中心 OpenAPI（上櫃） | 每日 |
| 受益人數 | 集保結算所 集保戶股權分散表 | 每週 |
| 近一年配息、殖利率、下次除息 | 證交所／櫃買 除權除息計算結果表與預告表 | 每日 |
| 管理費 | `config/etfs.json` 手動維護，依目前規模換算級距 | 費率異動時更新 |
| 資金流向（每週淨申購、受益人數增減） | 集保股權分散表的單位數與人數（`data/weekly.csv`，已回補一年），淨值取證交所 e添富 | 每週 |
| 成份股（股數、權重、期貨、債券） | 各投信每日申購買回清單：元大、群益、富邦、統一、凱基、復華（GitHub 每日抓）；國泰（網頁開啟時由裝置直接讀取） | 每日 |
| 個股市值排名、產業 | 證交所 OpenAPI 已發行股數 × 收盤價（上市）、櫃買中心 OpenAPI（上櫃） | 每日 |

某個來源失敗時，程式沿用上一次成功的資料，網頁上方會顯示警告，該次 Actions 也會標成失敗（GitHub 會寄信通知）。

國泰投信的網站防火牆會拒絕 GitHub 的美國主機（HTTP 403 Access Denied），但它的 API 允許其他網站跨網域讀取，
所以 00878 的成份股改由網頁開啟時從使用者的裝置直接向國泰讀取（設定檔 `pcf.client: true`），伺服器端讀不到不算失敗。
在台灣以外的網路、或國泰網站維護時，網頁會顯示「暫時讀不到」。

成份股輸出在 `data/holdings.json`，每筆為「種類、代號、名稱、數量、權重%」，種類 s=股票（股數）、f=期貨（口數）、b=債券（面額）、e=ETF；
`stocks` 欄位是個股的「市值（億）、產業」，給持股對照表排序用。

## 網頁功能
- **總覽／比較**：各 ETF 主要數字，可排序（含近 4 週資金流入）。
- **資金流向**：1／4／13 週淨申購（億元，紅＝流入、綠＝流出），ETF 詳情頁有近 13 週小圖。淨申購 = 單位數週變化 × 淨值；單位數一週變動超過 1.8 倍視為分割，不計入。
- **成份股 → 持股對照表**：直列是成份股（依市值排序，可選前 50／100／全部與產業），橫欄是 ETF（市值型、高股息、主動式），格子顯示權重%、張數或兩者；點一列看該股在各 ETF 的持有情形。
  - ⚙️ 欄位順序：勾選要顯示的 ETF、▲▼ 或拖曳 ≡ 調整位置，也可一鍵依規模／類型排序；設定存在手機瀏覽器裡（localStorage），重疊度矩陣同步套用。
  - ⛶ 全覽：一鍵把整張表縮放到滿版（隱藏底部分頁），只顯示權重，<0.05% 以「·」表示；橫放手機字會自動放大。
- **成份股 → 重疊度**：兩兩 ETF 共同持股的權重重疊比例。

## 新增或修改追蹤的 ETF
最簡單：在網頁總覽按「＋ 新增／刪除」，會開一張 GitHub Issue（標題「新增 ETF 00713」或「刪除 ETF 0056」），
`.github/workflows/manage.yml` 會用 `scripts/manage.py` 改清單、立刻更新資料，並在 Issue 回覆結果後關閉。只有 repo 擁有者開的 Issue 會生效。
自動帶入名稱、市場、類型（可指定）、配息次數；管理費留空待查，成份股自動接上元大、富邦、復華，其他投信需手動設定 `pcf`。

手動方式：編輯 `config/etfs.json`：代號、名稱、類型、市場（TWSE 上市／TPEX 上櫃）、每年配息次數、費率級距，以及 `pcf`（成份股來源投信與該投信的基金代碼）。目前支援的投信：yuanta、cathay、capital、fubon、uni、kgi、fhtrust；`client: true` 目前只支援 cathay。

## 檔案
- `index.html`：網頁本體；`sw.js`：離線快取（更新網頁時把 `CACHE` 版本號 +1）
- `manifest.webmanifest`、`icons/`：加入主畫面的名稱與圖示
- `scripts/update.py`：資料更新程式（只用 Python 標準函式庫）
- `config/etfs.json`：手動維護的欄位
- `data/`：自動產生的資料，不要手動修改
